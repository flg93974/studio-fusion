Installer Studio Fusion

Sur iPhone, l'appli s'installe depuis Safari, comme une appli :

  1. 1
    Touche Partagerle carré avec la flèche vers le haut, en bas de Safari.
  2. 2
    Choisis « Sur l'écran d'accueil »fais défiler la liste si besoin.
  3. 3
    Valide « Ajouter »l'icône apparaît sur l'écran d'accueil. Ouvre-la : elle s'affiche plein écran et reste utilisable hors ligne.

Attention : l'appli installée a son propre stockage, séparé de Safari. Tes sons enregistrés dans Safari ne seront pas visibles dans l'appli installée ; exporte-les d'abord si besoin.

Touche n'importe où pour fermer.

Studio Fusion

Un seul logiciel qui réunit la retouche d'image par calques (inspirée de Photoshop) et l'enregistrement / montage / mixage audio multipiste (inspiré de Pro Tools).

Espace Image

  • Outils : V déplacement, M sélection, C recadrage, B pinceau, E gomme, G pot de peinture, I pipette, T texte, U formes, X échanger les couleurs.
  • Sélections : W baguette magique, L lasso polygonal ; Maj ajoute, Alt soustrait ; Ctrl+A / D / Maj+I.
  • Masques de calque (non destructifs) : peignez en noir pour cacher, en blanc pour révéler ; Maj+clic sur la vignette pour désactiver, Alt+clic pour voir le masque seul. D = noir/blanc par défaut.
  • Calques avec opacité et modes de fusion, réglages dont Courbes, filtres, historique (Ctrl+Z).

Espace Audio

  • Fenêtre Édition : importez, enregistrez ou générez des sons ; déplacez, recadrez, séparez (B) les clips ; modes Shuffle / Slip / Grid ; lecture avec Espace.
  • Fondus réglables par les poignées des coins du clip (linéaire, puissance constante, exponentiel) ; gain de clip Ctrl+Maj+↑/↓, bouton Normaliser ; Strip Silence Ctrl+U ; mode Spot ; annuler/rétablir (Ctrl+Z/Y, 64 niveaux).
  • Fenêtre Mixage : faders, pan, mute/solo, 4 inserts par piste (EQ, compresseur, reverb, delay, distorsion), pistes aux avec 2 envois pré/post-fader par piste, limiteur de sécurité sur le master, export du mixage en WAV.
  • Enregistrer sur iPhone avec un casque : ouvrez la version en ligne dans Safari, branchez/connectez le casque, ouvrez le panneau Enregistrement (icône micro), choisissez le préréglage Bluetooth ou Calibrer, armez une piste (R) ou laissez l'appli créer la piste « Voix », puis ●. L'instru est jouée dans le casque pendant la prise ; la latence est compensée automatiquement, et vous pouvez recaler la prise de ±10 ms.
  • Sur iPhone : désactivez le mode silencieux. Avec un casque Bluetooth dont on utilise le micro, iOS passe en mode « appel » : qualité réduite. Pour une meilleure qualité, utilisez un casque filaire (ou des écouteurs EarPods).

Passerelle image ⇄ son

  • Sonifier le calque : le calque actif est lu comme une partition spectrale et devient un clip audio sur une nouvelle piste.
  • Spectrogramme du clip : sélectionnez un clip dans l'espace Audio ; son spectre devient un nouveau calque.
  • Édition spectrale : sur le calque spectrogramme, peignez en noir (ou utilisez un masque) pour effacer des fréquences, puis « Sonifier le calque » pour réentendre le résultat.

Clip vidéo

  • Bouton Clip vidéo (barre du haut) : fond « Ma caméra », « Pochette » (calque actif ou image importée) ou « Visualiseur », format 9:16, 1:1 ou 16:9.
  • Habillage : titre du projet, paroles en sous-titres (si elles sont saisies), forme d'onde et filtre couleur. Clip entier (3 min max) ou extrait de 5, 15 ou 30 s.
  • « Ma caméra » : décompte 3-2-1, puis lecture du mixage pendant le tournage (faites un playback). Le fichier est un MP4 quand le navigateur le permet, sinon un WebM.

Dans la page Claude, le micro est bloqué par le navigateur : pour enregistrer, ouvrez le fichier studio-fusion.html directement dans Chrome ou Edge. Le mixage WAV est livré dans un .zip.

Tout fonctionne dans le navigateur, rien n'est envoyé en ligne. Cliquez n'importe où pour fermer.
