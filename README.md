# Studio Fusion

Application web qui réunit retouche d'image (inspirée de Photoshop) et studio audio multipiste (inspiré de Pro Tools), avec une passerelle image ⇄ son.

Version en ligne : https://flg93974.github.io/studio-fusion/

Tout tourne dans le navigateur, aucune donnée n'est envoyée en ligne. L'enregistrement micro nécessite une adresse https (cette page GitHub Pages).
